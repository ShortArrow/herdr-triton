# 0011. Jump は、承認待ちが無ければ完了報告へ、それも無ければワークスペースへ移る

[English](../../adr/0011-jump-falls-back-to-done-then-workspaces.md) | 日本語

- Status: Accepted
- Date: 2026-09-29
- Amends: 0006（Jump の移動先）、0008（リスナーが終了する条件）

## Context

承認待ちをすべて片づけると、Jump は赤く光るだけで、キーパッドにできることが無くなる。
一方 herdr には、作業を終えてまだ見られていないエージェント（`done`）が残っている。
herdr は、`agent.focus` で画面に出したエージェントを確認済み、つまり `idle` にする（herdr `0d5d6f1`、`src/app/actions.rs`）。
`workspace.focus` でワークスペースを切り替えられる。

## Decision

Jump は、空でない最初の段を選び、その中を巡回する。
段の順は、承認待ちのエージェント、`done` のエージェント、全ワークスペースとする。
リスナーは、承認待ちか `done` がある間は動き続け、どちらも空になって 5 秒たったら終了する。
ワークスペースの段は、リスナーが動いている間（その 5 秒と `bridge run` を含む）だけ使える。

## Consequences

- `done` のエージェントは表示すると `idle` になるので、Jump を押すたびに1つずつ消化される
- Jump の LED で段を見分けられる。承認待ちは琥珀、`done` は緑、ワークスペースは白
- プラグインで動かしていて承認待ちも `done` も無いと、キーパッドは `NoHost` で、Jump は何もしない。いつでもワークスペースを巡回するには `bridge run` が要る
- ワークスペースの段の Jump は、`workspace.list` と `workspace.focus` の2回のリクエストになる

## Alternatives

- **承認待ち、`done`、ワークスペースを1本の輪にする**: 押すたびに先へ進むので、ワークスペースへ向かう途中で承認待ちを通り過ぎてしまう
- **ワークスペースをいつでも巡回できるよう、リスナーを常駐させる**: ADR 0008 の「待つものが無い間は何も動かさない」をやめることになる
