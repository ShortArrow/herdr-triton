# 0011. Jump は、承認待ちが無ければ完了報告へ、それも無ければ全エージェントへ移る

[English](../../adr/0011-jump-falls-back-to-done-then-every-agent.md) | 日本語

- Status: Accepted
- Amended by: [0012](0012-resident-listener-quiet-when-idle.md)
- Date: 2026-09-29
- Amends: 0006（Jump の移動先）、0008（リスナーが終了する条件）

## Context

承認待ちをすべて片づけると、Jump は赤く光るだけで、キーパッドにできることが無くなる。
一方 herdr には、作業を終えてまだ見られていないエージェント（`done`）が残っている。
herdr は、`agent.focus` で画面に出したエージェントを確認済み、つまり `idle` にする（herdr `0d5d6f1`、`src/app/actions.rs`）。
エージェントのいない pane へは、キーパッドでもキーボードでも同じ手間で移れる。

## Decision

Jump は、空でない最初の段を選び、その中を巡回する。
移動には `agent.focus` を使い、段の順は、承認待ちのエージェント、`done` のエージェント、`agent.list` の順の全エージェントとする。
リスナーは、承認待ちか `done` がある間は動き続け、どちらも空になって 5 秒たったら終了する。
最後の段は、リスナーが動いている間（その 5 秒と `bridge run` を含む）だけ使える。

## Consequences

- `done` のエージェントは表示すると `idle` になるので、Jump を押すたびに1つずつ消化される
- Jump の LED で段を見分けられる。承認待ちは琥珀、`done` は緑、全エージェントは白
- プラグインで動かしていて承認待ちも `done` も無いと、キーパッドは `NoHost` で、Jump は何もしない。いつでもエージェントを巡回するには `bridge run` が要る
- どの段も bridge がすでにポーリングしているスナップショットを使うので、Jump のリクエストはどの段でも1回で済む

## Alternatives

- **承認待ち、`done`、全エージェントを1本の輪にする**: 押すたびに先へ進むので、ほかのエージェントへ向かう途中で承認待ちを通り過ぎてしまう
- **最後の段で全ワークスペースを巡回する**: 最初はこれで試した。エージェントのいないワークスペースにも止まるが、そこへはキーボードでも同じ手間で移れる。押すたびに `workspace.list` と `workspace.focus` が要る
- **エージェントをいつでも巡回できるよう、リスナーを常駐させる**: ADR 0008 の「待つものが無い間は何も動かさない」をやめることになる
