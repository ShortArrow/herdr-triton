# 0007. 1つの bridge は herdr のセッションを1つだけ受け持つ

- Status: Accepted
- Date: 2026-09-28

## Context

herdr のセッションはそれぞれ別のサーバーで、ソケットも別になる。
ターミナルは、接続した1つのセッションを表示する。
`agent.focus` はそのセッションのクライアントの中で pane を切り替えるだけで、そのセッションのターミナルウィンドウを前面に出しはしない。
ユーザーがどのセッションのターミナルを見ているかは、herdr の API からは分からない。

## Decision

`bridge` は1つのセッションにつなぐ。
`--session <name>` でセッションを選び、`HERDR_SOCKET_PATH` より優先する。
指定が無ければ、herdr と同じ規則でソケットを決める。

## Consequences

- キュー、Jump、LED が扱うのは1つのセッションだけになる
- 別のセッションでキーパッドを使うには、`--session` を変えて `bridge` を起動し直す
- herdr の pane の中で `--session` を付けずに起動した `bridge` は、その pane の `HERDR_SOCKET_PATH` を通じて、その pane のセッションを受け持つ

## Alternatives

- **全セッションをポーリングしてキューをまとめる**: 別のセッションの pane へ Jump すると、そのセッションの中でフォーカスは移るが、ターミナルは前面に出ないので、何も起きなかったように見える
- **画面に出ているセッションに追従する**: どのセッションのターミナルが前面にあるかを herdr の API で知る手段が無い
